SAI Statistics — Guide de l'utilisateur

SAI Statistics est une application de statistiques de bureau multiplateforme, construite sur le moteur R. Ce guide présente les principaux flux de travail et les points utiles à connaître si vous venez de SPSS.

1. Importer et enregistrer des données

Utilisez Fichier ▸ Importer des données pour ouvrir des fichiers CSV/texte, Excel (.xlsx), SPSS (.sav, .zsav, .por), Stata (.dta) ou SAS (.sas7bdat, .xpt). Les données sont écrites directement dans la base de données intégrée à l'application : il n'y a pas d'étape de chargement distincte à attendre, même pour de gros fichiers.

Plus de 200 000 lignes : la Vue des données affiche l'ensemble des données sans pagination. Après l'importation d'un jeu de données plus volumineux, une boîte d'information s'affiche ; il ne s'agit que d'un avertissement, rien n'est bloqué. Le défilement peut devenir plus lent, mais les analyses ne sont pas affectées : chaque analyse lit directement la base de données, et non ce qu'affiche la Vue des données.

Fichier ▸ Enregistrer sauvegarde votre travail dans le format propre à l'application, .sdf : données, définitions des variables et mise en forme des cellules tiennent dans un seul fichier, et sa réouverture ne nécessite aucune importation. Fichier ▸ Exporter des données produit des fichiers CSV, Excel ou SPSS (.sav).

2. Vue des variables — qu'est-ce qui influence réellement les analyses ?

Une remarque importante pour les utilisateurs venant de SPSS : certains champs de la Vue des variables sont purement cosmétiques, tandis que d'autres modifient réellement les résultats des analyses. Le tableau ci-dessous indique lesquels.

Champ Effet Détails
Manquant (valeurs manquantes définies par l'utilisateur) ✅ Réel Les codes de valeurs manquantes que vous définissez (par ex. -99) sont exclus des statistiques de cette variable dans les analyses.
Décimales ✅ Réel (affichage) Détermine le nombre de décimales affichées pour les valeurs, par exemple dans le tableau des Effectifs.
Mesure (Nominal / Ordinal / Échelle) 🟡 Partiel Place en tête des listes de variables des boîtes de dialogue les variables du niveau de mesure correspondant. Ce n'est pas un filtre : vous pouvez toujours choisir n'importe quelle variable.
Rôle 🟡 Partiel Préremplit une seule fois les zones cibles et d'entrée, à la première ouverture de certaines boîtes de dialogue.
Largeur ❌ Cosmétique Modifie uniquement l'affichage des cellules dans la Vue des données ; n'affecte jamais les résultats.

En résumé : prenez au sérieux la définition des valeurs manquantes — ce sont les champs qui modifient les résultats statistiques. Les autres servent surtout à conserver la disposition habituelle de SPSS.

3. Pondérer les observations / Fractionner le fichier / Sélectionner des observations

Une fois activés dans le menu Données, ces trois réglages s'appliquent automatiquement à toutes les analyses suivantes — inutile de les redéfinir dans chaque boîte de dialogue :

  • Pondérer les observations : les analyses de base comme Effectifs, Tableaux croisés, Statistiques descriptives, Moyennes, les tests t et l'ANOVA utilisent de véritables formules pondérées (et non une duplication de lignes). Une analyse qui ne prend pas en charge la pondération l'indique par un avertissement dans ses résultats, au lieu d'ignorer silencieusement le poids.
  • Fractionner le fichier : produit des résultats séparés pour chaque groupe lorsque l'analyse le permet ; sinon, les résultats affichent un avertissement.
  • Sélectionner des observations : limite les lignes lues par chaque analyse.
Si un résultat diffère de ce que vous attendiez, vérifiez d'abord la barre d'état : elle indique toujours l'état de la pondération, du fractionnement et du filtre (par exemple Filtre : ACTIVÉ).

4. Lancer une analyse

Choisissez une procédure dans le menu Analyse, placez les variables dans les zones cibles par glisser-déposer ou par double-clic, ouvrez si besoin les sous-boîtes de dialogue comme Statistiques ou Options, puis cliquez sur OK. Le résultat apparaît dans la Vue des résultats. Chaque boîte de dialogue propose également :

  • Coller le code R — affiche le code R qui sera exécuté (transparence totale).
  • Coller la syntaxe — écrit la commande de syntaxe SPSS équivalente dans l'onglet Syntaxe / Terminal, afin de pouvoir l'enregistrer et la relancer plus tard.
  • Clavier : Tab/Maj+Tab passe d'un champ à l'autre, Entrée valide, Échap annule.

5. Résultats — formats et exportation

Chaque bloc de la Vue des résultats peut être réduit ou supprimé. Le style de tableau (Académique / Compact / APA) se choisit dans Édition ▸ Préférences. Fichier ▸ Enregistrer les résultats en HTML... crée un fichier HTML unique et autonome que vous pouvez partager par e-mail ; Fichier ▸ Exporter les résultats enregistre les résultats au format HTML, PDF, Word, Excel, CSV ou Markdown.

6. Onglet Syntaxe / Terminal

L'onglet Syntaxe / Terminal (Ctrl+5) propose deux modes :

  • Mode syntaxe SPSS : saisissez des commandes SPSS classiques comme FREQUENCIES VARIABLES=age. Elles passent par les mêmes analyses et les mêmes contrôles de saisie que les menus — aucun code arbitraire n'est exécuté.
  • Mode console R : une session R interactive, semblable à RStudio. Le code s'exécute uniquement sur votre propre ordinateur et seulement lorsque vous cliquez sur Exécuter — rien ne s'exécute automatiquement, même si un fichier ouvert contient du code. Vous pouvez désactiver la console dans Édition ▸ Préférences ▸ Activer la console R.

7. Accessibilité

La navigation au clavier (Tab/Entrée/Échap, le focus reste dans les boîtes de dialogue), un thème Contraste élevé et la prise en charge des lecteurs d'écran (régions dynamiques, rôles ARIA) sont disponibles dans toutes les boîtes de dialogue et dans la Vue des résultats. La Vue des données et la Vue des variables sont des grilles HTML dotées de rôles ARIA, afin que les lecteurs d'écran puissent lire leurs cellules, et les tableaux de résultats sont de véritables tableaux HTML.

Conseil pour les gros jeux de données : pour rester fluide, la Vue des données n'affiche que les lignes actuellement visibles à l'écran. Pour examiner un gros jeu de données avec un lecteur d'écran, résumez-le avec Effectifs ou Statistiques descriptives et lisez les tableaux dans la Vue des résultats plutôt que de parcourir les cellules une à une.
