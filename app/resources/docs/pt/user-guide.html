SAI Statistics — Guia do Usuário

O SAI Statistics é um aplicativo de estatística para desktop, multiplataforma, construído sobre o motor R. Este guia apresenta os fluxos de trabalho principais e os pontos que vale a pena conhecer se você vem do SPSS.

1. Importar e salvar dados

Use Arquivo ▸ Importar Dados para abrir arquivos CSV/texto, Excel (.xlsx), SPSS (.sav, .zsav, .por), Stata (.dta) ou SAS (.sas7bdat, .xpt). Os dados são gravados diretamente no banco de dados integrado do aplicativo — não há uma etapa de carregamento separada para esperar, mesmo com arquivos grandes.

Mais de 200.000 linhas: a Visualização de Dados mostra o conjunto de dados inteiro sem paginação. Ao importar um conjunto maior, aparece uma caixa de informação — é apenas um aviso e não bloqueia nada. A rolagem pode ficar mais lenta, mas as análises não são afetadas: cada análise lê diretamente do banco de dados, e não do que a Visualização de Dados está exibindo.

Arquivo ▸ Salvar guarda o seu trabalho no formato próprio do aplicativo, .sdf — dados, definições de variáveis e formatação de células em um único arquivo, de modo que reabri-lo não exige nenhuma etapa de importação. Arquivo ▸ Exportar Dados grava arquivos CSV, Excel ou SPSS (.sav).

2. Visualização de Variáveis — o que realmente afeta as análises?

Uma observação importante para quem vem do SPSS: alguns campos da Visualização de Variáveis são puramente cosméticos, enquanto outros alteram de fato os resultados das análises. A tabela abaixo mostra quais são quais.

Campo Efeito Detalhes
Omisso (valores omissos definidos pelo usuário) ✅ Real Os códigos de valor omisso que você definir (p. ex. -99) são excluídos das estatísticas dessa variável nas análises.
Decimais ✅ Real (exibição) Controla o número de casas decimais exibidas nos valores, por exemplo na tabela de Frequências.
Medida (Nominal / Ordinal / Escala) 🟡 Parcial Move para o topo das listas de variáveis das caixas de diálogo as variáveis do nível de medida correspondente. Não é um filtro — você ainda pode escolher qualquer variável.
Papel 🟡 Parcial Preenche uma única vez as caixas de destino e de entrada, na primeira abertura de alguns diálogos.
Largura ❌ Cosmético Altera apenas como a Visualização de Dados exibe as células; nunca afeta os resultados.

Resumindo: leve a sério as definições de valores omissos — são os campos que alteram os resultados estatísticos. Os demais servem principalmente para manter o layout familiar do SPSS.

3. Ponderar Casos / Dividir Arquivo / Selecionar Casos

Depois de ativadas no menu Dados, estas três configurações se aplicam automaticamente a todas as análises seguintes — você não precisa configurá-las de novo em cada caixa de diálogo:

  • Ponderar Casos: análises básicas como Frequências, Tabelas de Contingência, Descritivas, Médias, os testes t e a ANOVA usam fórmulas ponderadas reais (e não duplicação de linhas). Uma análise que não oferece suporte a ponderação avisa isso nos resultados, em vez de ignorar o peso silenciosamente.
  • Dividir Arquivo: gera resultados separados para cada grupo quando a análise permite; caso contrário, os resultados mostram um aviso.
  • Selecionar Casos: limita as linhas que cada análise lê.
Se um resultado parecer diferente do esperado, verifique primeiro a barra de status: ela sempre mostra o estado de ponderação, divisão e filtro (por exemplo Filtro: ATIVADO).

4. Executar uma análise

Escolha um procedimento no menu Analisar, mova as variáveis para as caixas de destino arrastando e soltando ou com duplo clique, abra subdiálogos como Estatísticas ou Opções se necessário e clique em OK. O resultado aparece na Visualização de Resultados. Toda caixa de diálogo também oferece:

  • Colar Código R — mostra o código R que será executado (transparência total).
  • Colar Sintaxe — grava o comando de sintaxe SPSS equivalente na aba Sintaxe / Terminal, para que você possa salvá-lo e executá-lo de novo mais tarde.
  • Teclado: Tab/Shift+Tab alterna entre os campos, Enter confirma e Esc cancela.

5. Resultados — formatos e exportação

Cada bloco da Visualização de Resultados pode ser recolhido ou removido. O estilo de tabela (Acadêmico / Compacto / APA) é definido em Editar ▸ Preferências. Arquivo ▸ Salvar Resultados como HTML... cria um único arquivo HTML autônomo que você pode compartilhar por e-mail; Arquivo ▸ Exportar Resultados salva os resultados como HTML, PDF, Word, Excel, CSV ou Markdown.

6. Aba Sintaxe / Terminal

A aba Sintaxe / Terminal (Ctrl+5) tem dois modos:

  • Modo de sintaxe SPSS: escreva comandos SPSS clássicos, como FREQUENCIES VARIABLES=idade. Eles passam pelas mesmas análises e pelas mesmas verificações de entrada dos menus — nenhum código arbitrário é executado.
  • Modo de console R: uma sessão R interativa, semelhante ao RStudio. O código é executado somente no seu próprio computador e somente quando você clica em Executar — nada é executado automaticamente, mesmo que um arquivo aberto contenha código. Você pode desativar o console em Editar ▸ Preferências ▸ Ativar o console R.

7. Acessibilidade

A navegação pelo teclado (Tab/Enter/Esc, com o foco mantido dentro das caixas de diálogo), um tema de Alto Contraste e o suporte a leitores de tela (regiões dinâmicas, papéis ARIA) estão disponíveis em todas as caixas de diálogo e na Visualização de Resultados. A Visualização de Dados e a Visualização de Variáveis são grades HTML com papéis ARIA, de modo que os leitores de tela podem ler suas células, e as tabelas de resultados são tabelas HTML reais.

Dica para conjuntos de dados grandes: para manter a fluidez, a Visualização de Dados desenha apenas as linhas visíveis na tela. Para revisar um conjunto grande com um leitor de tela, resuma-o com Frequências ou Descritivas e leia as tabelas na Visualização de Resultados, em vez de percorrer célula por célula.
