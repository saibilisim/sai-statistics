SAI Statistics — Guida utente

SAI Statistics è un'applicazione di statistica per desktop, multipiattaforma, costruita sul motore R. Questa guida descrive i flussi di lavoro principali e i punti utili da conoscere se si proviene da SPSS.

1. Importare e salvare i dati

Usa File ▸ Importa dati per aprire file CSV/testo, Excel (.xlsx), SPSS (.sav, .zsav, .por), Stata (.dta) o SAS (.sas7bdat, .xpt). I dati vengono scritti direttamente nel database integrato dell'applicazione: non c'è una fase di caricamento separata da attendere, nemmeno con file di grandi dimensioni.

Oltre 200.000 righe: la Vista dati mostra l'intero set di dati senza paginazione. Dopo aver importato un set di dati più grande compare una finestra informativa: è solo un avviso e non blocca nulla. Lo scorrimento può rallentare, ma le analisi non ne sono influenzate: ogni analisi legge direttamente dal database, non da ciò che mostra la Vista dati.

File ▸ Salva memorizza il tuo lavoro nel formato proprio dell'applicazione, .sdf: dati, definizioni delle variabili e formattazione delle celle in un unico file, così riaprirlo non richiede alcuna importazione. File ▸ Esporta dati scrive file CSV, Excel o SPSS (.sav).

2. Vista variabili — cosa influisce davvero sulle analisi?

Una nota importante per chi proviene da SPSS: alcuni campi della Vista variabili sono puramente estetici, mentre altri modificano davvero i risultati delle analisi. La tabella seguente mostra quali sono quali.

Campo Effetto Dettagli
Mancante (valori mancanti definiti dall'utente) ✅ Reale I codici di valore mancante che definisci (ad es. -99) vengono esclusi dalle statistiche di quella variabile nelle analisi.
Decimali ✅ Reale (visualizzazione) Controlla il numero di decimali mostrati per i valori, ad esempio nella tabella delle Frequenze.
Misura (Nominale / Ordinale / Scala) 🟡 Parziale Sposta in cima agli elenchi di variabili delle finestre di dialogo le variabili del livello di misura corrispondente. Non è un filtro: puoi comunque scegliere qualsiasi variabile.
Ruolo 🟡 Parziale Precompila una sola volta le caselle di destinazione e di input, alla prima apertura di alcune finestre di dialogo.
Larghezza ❌ Estetico Cambia solo il modo in cui la Vista dati mostra le celle; non influisce mai sui risultati.

In sintesi: prendi sul serio le definizioni dei valori mancanti: sono i campi che cambiano i risultati statistici. Gli altri servono soprattutto a mantenere il layout familiare di SPSS.

3. Pondera casi / Suddividi file / Seleziona casi

Una volta attivate nel menu Dati, queste tre impostazioni si applicano automaticamente a tutte le analisi successive: non serve reimpostarle in ogni finestra di dialogo:

  • Pondera casi: le analisi principali come Frequenze, Tavole di contingenza, Descrittive, Medie, i test t e l'ANOVA usano vere formule ponderate (non la duplicazione delle righe). Un'analisi che non supporta la ponderazione lo segnala con un avviso nell'output, invece di ignorare silenziosamente il peso.
  • Suddividi file: produce risultati separati per ciascun gruppo quando l'analisi lo consente; altrimenti l'output mostra un avviso.
  • Seleziona casi: limita le righe lette da ogni analisi.
Se un risultato appare diverso da quello atteso, controlla prima la barra di stato: mostra sempre lo stato di ponderazione, suddivisione e filtro (ad esempio Filtro: ATTIVO).

4. Eseguire un'analisi

Scegli una procedura dal menu Analizza, sposta le variabili nelle caselle di destinazione trascinandole o con un doppio clic, apri se necessario le finestre secondarie come Statistiche od Opzioni e fai clic su OK. Il risultato compare nella Vista output. Ogni finestra di dialogo offre inoltre:

  • Incolla R: mostra il codice R che verrà eseguito (piena trasparenza).
  • Incolla sintassi: scrive il comando di sintassi SPSS equivalente nella scheda Sintassi / Terminale, così puoi salvarlo ed eseguirlo di nuovo in seguito.
  • Tastiera: Tab/Maiusc+Tab passa da un campo all'altro, Invio conferma, Esc annulla.

5. Output — formati ed esportazione

Ogni blocco della Vista output può essere compresso o rimosso. Lo stile delle tabelle (Accademico / Compatto / APA) si imposta in Modifica ▸ Preferenze. File ▸ Salva output come HTML... crea un unico file HTML autonomo che puoi condividere via e-mail; File ▸ Esporta output salva i risultati come HTML, PDF, Word, Excel, CSV o Markdown.

6. Scheda Sintassi / Terminale

La scheda Sintassi / Terminale (Ctrl+5) ha due modalità:

  • Modalità sintassi SPSS: scrivi comandi SPSS classici come FREQUENCIES VARIABLES=eta. Vengono eseguiti tramite le stesse analisi e gli stessi controlli sui dati in ingresso dei menu: non viene eseguito alcun codice arbitrario.
  • Modalità console R: una sessione R interattiva, simile a RStudio. Il codice viene eseguito solo sul tuo computer e solo quando fai clic su Esegui: nulla viene eseguito automaticamente, anche se un file aperto contiene codice. Puoi disattivare la console in Modifica ▸ Preferenze ▸ Abilita la console R.

7. Accessibilità

La navigazione da tastiera (Tab/Invio/Esc, con il focus mantenuto all'interno delle finestre di dialogo), un tema a Contrasto elevato e il supporto per i lettori di schermo (regioni dinamiche, ruoli ARIA) sono disponibili in tutte le finestre di dialogo e nella Vista output. La Vista dati e la Vista variabili sono griglie HTML con ruoli ARIA, così i lettori di schermo possono leggerne le celle, e le tabelle di output sono vere tabelle HTML.

Suggerimento per i set di dati di grandi dimensioni: per restare veloce, la Vista dati disegna solo le righe attualmente visibili a schermo. Per esaminare un set di dati grande con un lettore di schermo, riassumilo con Frequenze o Descrittive e leggi le tabelle nella Vista output invece di spostarti cella per cella.
